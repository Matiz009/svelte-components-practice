# Svelte Components Practice

Svelte practice: a smiley face reacts to the answers you pick in a short conversation.

## Components

- `Header`, `Container`, `Face`, `Buttons`, composed in `App.svelte`
- `story.js`: conversation steps, each with answer buttons that change the face's mood

## Tech stack

Svelte · JavaScript
